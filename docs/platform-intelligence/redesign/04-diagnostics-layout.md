# 波动归因布局

这是诊断工作台，不是指标列表。波动页和旧的分析页合成这一屏。从总览点进来时，指标已经选好。直接打开这一页时，默认选中总览的第一个 KPI：活跃人数（DAU）。

## 页面结构

```
顶栏（与总览相同的平台、区间、口径、对比、币种）

页头
  标题：波动归因
  副文：当前指标的原列名和别名。演示数据条与总览相同

左栏  指标选择，宽约 240 像素，本页内滚动
  分组：经营、用户、资金、游戏
  每行：名称 + 百分比小标记
  选中行有浅底。搜索框按名称过滤

右主区
  第一块  结论条（紧凑，一行到两行）
    指标名
    当期    对比期    差额    百分比
    对账：通过 / 不一致 / 这个指标没有重算式

  第二块  历史趋势，高约 300 像素
    实线：分析区间
    虚线或点：对比期对应的值
    图例写明两条线各是什么

  第三块  左右分栏
    左  因素拆解（瀑布图 + 表）
    右  维度贡献（页签 + 表）

  第四块  四层说明，四列横排
    已核对的变化
    可量化的驱动
    原因假设
    待调查
```

窄于 1100 像素时，左栏改到主区上面，因素和维度上下叠，四层改为两列。

## 因素拆解

只画指标中心里已经对上的关系。瀑布从对比期走到当期，每一根柱是一个分项的差额。

当前能拆的只有这些：

| 指标 | 分项 |
| --- | --- |
| 充值人数 | 首充人数的变化、老用户充值人数的变化 |
| 充值金额 | 人数变化带来的金额、人均变化带来的金额。人均要和全量 Arppu 对得上 |
| 公司输赢（GGR） | 投注金额的变化、返奖金额的变化（减去）。等式不通过时，瀑布关掉，只留原列 |
| 充提差 | 充值金额的变化、提现金额的变化（减去）、KOL工资的变化 |

没有加法或已对账乘法关系的指标，例如活跃人数（DAU），瀑布区写：「没有已核对的分项。下面的维度也要等对应报表。」不发明一个拆法。

表和瀑布用同一组数。列：分项、对比期、当期、差额、占父项差额。父项差额为 0 时，占比留空。按差额绝对值排序。点一行，趋势图临时只强调这个分项，不离开本页。

## 维度贡献

四个页签：用户类型、渠道、支付通道、游戏厂商。

表的目标列是：维度、对比期、当期、差额、贡献占比。有数据时按贡献绝对值从大到小。点一行，从右侧滑出下钻面板，本页不跳走。

现在日报能填的只有一个格子：

- 指标是充值人数，页签是用户类型：两行，首充人数、老用户充值人数。这和因素拆解是同一条等式，维度页签里再列一次，是为了和以后的渠道表用同一套交互。
- 不许出现「新充 / 老用户」这种拆法。那条等式 46 天都不成立。

其余页签，以及活跃人数、充值金额、公司输赢上的用户类型，都是空状态。空状态写明缺的报表，例如：

- 渠道：没有渠道或代理日报
- 支付通道：没有支付通道日报，也不显示支付成功率
- 游戏厂商：没有游戏与厂商明细

空表保留表头，不填示例占比，不把总盘数字拆成假的前三名。

## 下钻面板

宽约 360 像素，盖在主区右侧。

- 维度名和它的差额、百分比
- 这个维度在分析区间里的趋势。没有明细时，面板不打开，行本身不可点
- 证据：平台、日期、指标、用的批次。演示时批次写「演示」
- 按钮：加入待调查。写入分析报告的草稿，不生成原因句

## 四层说明

四层始终都在，不能合成一段。

- **已核对的变化：** 当期、对比期、差额、百分比、口径（结束日或区间合计）。
- **可量化的驱动：** 瀑布里那些分项的名字。没有就写没有。
- **原因假设：** 空白，直到你在分析报告里写了一句，并标成「未经数据证实」。系统不起草这句话。
- **待调查：** 缺的报表名，加上你从下钻里加入的条目。

## 和旧波动页、分析页的差别

- 不再先给你一张全部指标的大表，再点进另一页看四段话。
- 选指标、看变化、看趋势、看拆解、看维度，在同一屏完成。
- 维度贡献的位置先留好。没有报表的维度是明确的空，不是隐藏。
