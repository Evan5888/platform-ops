# 交互流程

顶栏的平台、区间、统计口径、对比周期、币种，在同一次打开里保持。从总览走到归因、再走到专题，这些条件不变。刷新后回到默认：Afun-MX、演示区间的最后一天、口径为结束日、对比为前一日、比索。这一版不把筛选存进数据库。

## 在总览上筛选

1. 选择平台。标题、KPI、趋势、异常全部换成这个平台。不把另一个平台的数留在角落。
2. 改分析区间。趋势的横轴跟着变。口径是「结束日」时，KPI 仍是新的结束日，不是区间的和。
3. 把口径改成「区间合计」。每个 KPI 的标签变成「日合计 · N 天」，主数字变成相加。人数格的问号重复：不是去重。
4. 改对比周期。差额、百分比、异常条、波动列表一起重算。对比期缺失的格子显示「—」，不显示 0%。
5. 改币种。金额按该平台汇率换算，并在问号里写明用的是原文件还是汇率。人数字不变。演示汇率必须标「演示」。

## 从总览进入诊断

以下动作都打开波动归因，并带上当前筛选和被点的指标：

- 点 KPI 格
- 点异常条上的「诊断」
- 点主要波动列表的一行
- 点主趋势图例里的某个指标名

点趋势图上的某一天，不离开总览，只把结束日改成那一天。

## 在诊断工作台里操作

1. 左栏点另一个指标。结论条、趋势、瀑布、维度和四层换成这个指标。顶栏的平台和日期不动。
2. 搜索指标。只过滤左栏，不改变已经选中的指标，除非你点了一行。
3. 悬停趋势。看到当天和对比值。
4. 点瀑布或因素表的一行。趋势图突出该分项，表行保持选中。再点一次取消突出。
5. 切换维度页签。有行则可点。空状态没有可点的行。
6. 点有数据的维度行。右侧打开下钻面板。关掉面板不改变选中的指标。
7. 「加入待调查」把平台、日期、指标、维度和当时的差额放进分析报告草稿。不写原因。

诊断页不提供「导出图片」和「自动写结论」。那不是这一步的范围。

## 专题页怎么接进来

用户、充值与提现、游戏与厂商使用同一顶栏。

- 页内第一屏仍是紧凑 KPI 和一条趋势，不用总览那种大竖卡。
- 每个 KPI 点进波动归因，指标预选好。
- 留存、支付成功率、厂商贡献使用空状态组件。空状态里有报表名称，没有假进度条。

这一步只定义交互。专题页的完整版式在总览和归因确认之后再画，避免三套布局一起返工。

## 数据中心、指标中心、分析报告

这一步只定入口和回流，不实现导入。

- 顶栏「数据」进入数据中心。确认导入的流程仍是：预览、映射、校验、再确认。确认前不改总览数字。
- 指标中心是只读口径表，外加指标之间的关系（谁能拆成谁）。关系及公式以已核对文档为准。页面上不提供「改公式」按钮。
- 分析报告列出你保存的条目。从诊断页「加入待调查」或手写一句原因进来。原因句始终带「未经数据证实」。

## 空状态和演示

- 空状态占住本来该放图或表的区域，不用一整页空白代替。
- 文案格式固定：「没有〔报表名〕。有这张表之后，这里按贡献排序。」
- 演示数据：页头一条横幅，顶栏汇率旁一个「演示」标记。横幅文案：「演示数据。这些数字是为了看布局编的，不是 Afun-MX 或 Betroia 的日报。」
- 深色主题切换时，横幅、空状态、图表轴线一起换色。不留下一块仍是浅色的图。

## 键盘和指针

- 顶栏筛选项可用键盘切换。
- 指标左栏可用上下方向键移动选中项。
- 问号用悬停或焦点打开，不用点一下才出现、点外面才消失的弹层。
- 下钻面板可用 Esc 关闭。
