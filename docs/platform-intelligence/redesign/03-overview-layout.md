# 经营总览布局

桌面优先。下面按宽 1440 像素描述。窄屏时 KPI 从 6 列收到 4 列、再收到 2 列，图和表改成上下排，不隐藏指标。

总览不是「三张大卡 + 用户一块 + 游戏一块」。用户和游戏回到各自的专题页。

## 页面结构

```
顶栏（全站共用，见信息架构）

页头
  标题：Afun-MX · 经营总览
  副文：统计口径 · 对比周期 · 若是演示则显示「演示数据」条

第一行  异常条
  最多 4 条波动最大的指标，横向排列
  每条：指标名、差额、百分比、一个「诊断」入口
  没有达到阈值时，这条区域写「所选对比下没有超过阈值的波动」

第二行  KPI 网格，6 列
  每格约 88 像素高，不是竖向大卡
  格内：名称、主数字、对比差额和百分比、一条 48 像素高的迷你趋势

第三行  主趋势，占满内容宽
  高度约 320 像素
  默认可同时看：活跃人数（DAU）、充值金额、公司输赢（GGR）
  图例可开关。人数和金额不画在同一条纵轴上：左轴人数，右轴金额

第四行  两列
  左：主要波动列表，按绝对变化从大到小，点一行进入诊断
  右：对账状态。列出等式是否通过。失败的日期标出，不改原数
```

## KPI 网格里放哪些

默认 6 个，顺序固定，和指标中心的登记一致：

1. 活跃人数（DAU）
2. 充值金额
3. 充值人数
4. 充提差
5. 投注金额
6. 公司输赢（GGR）

注册、首充、新充、提现、KOL工资不挤在总览第一屏。它们在专题页，也会出现在「主要波动」里（如果变化排进前几名）。总览要的是经营结果，不是把日报每一列都铺开。

每格都可点，进入波动归因，并选中这个指标。

## 异常条的规则

同时满足才出现：

- 对比期有数，且对比期不是 0（百分比算得出）。
- 绝对百分比达到或超过 10%。

10% 是显示阈值，不是业务警报标准。指标中心里以后可以改，这一版先用 10%，并在异常条旁用问号写明。对账失败单独出现在右侧「对账状态」，不和涨跌混成一句话。

异常条不写「因为渠道」或「因为活动」。

## 主趋势

- 横轴是分析区间里的已有日期。缺日留空，不连成 0。
- 对比周期是「上周同日」时，可以再叠一条虚线，表示 7 日前的那一点所在的序列。不做成年对年。
- 悬停看到当天的原值和对比值。
- 点图上的某一天，把顶栏的结束日改成这一天。KPI 跟着变。这是总览上唯一会改日期的图上操作。

## 主要波动列表

列：指标、当期、对比期、差额、百分比。按差额的绝对值排序。人数和金额分开排序，避免金额永远排在人数前面。上下两小段：金额、人数。各取前 5。点一行进入诊断。

## 和旧总览的差别

- 去掉用户块、游戏块和「过去七天」塞在大卡底部的写法。七天若要看，用顶栏的区间加上「区间合计」。
- 数字字号降到能扫读的一排，而不是三张海报。
- 异常和波动是总览的主角，图是第二主角。
- 演示条贴在页头，不靠用户自己记得这是假数。
