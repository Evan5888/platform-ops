# 第一版功能清单

第一版指阶段 1 到阶段 4 做完、你能用来看现有日报的那个版本。阶段 0 只出本文档，不包含功能。

## 要做

- 选择 Afun-MX 或 Betroia。
- 选择开始日期和结束日期。结束日期决定「当天」，前一天用来对比。
- 切换比索和美金。人数不变。金额用对应原文件。
- 总览卡片：活跃人数、注册人数、充值人数、首充人数、新充人数、充值金额、提现金额、充提差、投注金额、返奖金额、公司输赢。
- 每张卡片显示结束日的值，以及相对前一天的差额和百分比。前一天没有数据时不显示百分比，也不把缺失当成 0。
- 趋势图覆盖所选日期范围。
- 用户页展示新充、首充，以及文件里已有的老用户充值人数。老用户金额留空，并说明缺「老用户充值金额」。
- 支付页只展示充值、提现、充提差和已核对的算式。
- 游戏页只展示全平台投注、返奖、公司输赢。厂商和游戏表为空，直到有游戏报表。
- 导入 CSV 和 Excel，预览，确认后按平台、日期、币种写入。
- 识别并丢弃「总计」行。
- 同一平台、同一天、同一币种再次导入时，明确提示将覆盖这一天，并留下旧版本记录。
- 保存这个日报类型的字段映射模板。两个平台可以共用一套模板，也可以以后分开。
- 导入后跑已核对等式。对不上的日期标出来，不悄悄改数。
- 指标页列出每条口径、公式和它来自哪一列。
- 波动页对已核对的分项做贡献排序。
- 本地保存一条分析笔记：平台、日期、指标、你写的结论、系统附上的证据。

## 明确不做

- 登录、角色、共享链接。
- AI 问答。
- 渠道、推广消耗、支付通道、游戏厂商占比。
- 把活跃人数改名为 DAU，或把公司输赢改名为 GGR。
- 自动把两个平台合成一个总数。
- 用汇率去改人数。
- 在彩金不为 0 的新数据到来之前，把「公司输赢 = 投注 − 返奖」写成永远成立。它只对当前这批数据成立。
