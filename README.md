# 运营看板

每日一次的运营台。数字只来自导入的 CSV 或 Excel，不连接后台，也不会显示估算。

## 运行

```bash
cd /agent
npm install
npm run dev
```

打开 http://127.0.0.1:5173

## 收件夹

固定文件夹：

`/cursor/stores/bc-93ae83e4-a329-4f86-98a1-8b6b50ccefa7/internal/dashboard-inbox`

把导出文件放进去，在页面上刷新收件夹，再点导入。聊天里收到的文件用「选择文件」。导入结果保存在这个浏览器的 localStorage。

换文件夹时设置环境变量 `DASHBOARD_INBOX`。

## 页面

- 侧栏切换 Afun-MX、Betroia 和汇总对照。平台名单在 `src/data/platforms.ts`。
- 功能栏选择数据日期、显示币种，并看到每个平台自己的汇率。
- 用户：新充用户、首充用户、老用户，以及这两天人数变化由谁带动。
- 游戏与厂商：按厂商和游戏列出文件里的指标。

数据日期是墨西哥自然日。当天结束后再过 3 小时，这一天才进入可导入窗口。

显示币种可以在墨西哥比索和美金之间切换。文件用币种列或文件名标明货币，也可以在导入时指定。只导入了一种货币时，另一种货币的金额按该平台已保存的汇率换算。人数不换算。没有汇率时，金额留空，不估计。

每个平台各自保存一条汇率，含义是 1 美金可兑换的墨西哥比索。汇率文件还没到之前，功能栏里的汇率留空。列名示例见 `samples/rate-format.csv`，里面没有数字。

日报列名示例见 `samples/daily-export-format.csv`。该文件没有业务数字。
